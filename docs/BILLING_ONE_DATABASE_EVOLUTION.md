# BILLING_ONE EXTENDED — TIẾN HÓA CƠ SỞ DỮ LIỆU (DATABASE EVOLUTION)

> **Tài liệu chiến lược nâng cấp và mở rộng lược đồ PostgreSQL**  
> **Target Database:** PostgreSQL 16 (Source of Truth)  
> **Nguyên tắc vàng:**  
> 1. TUYỆT ĐỐI KHÔNG `DROP DATABASE` hoặc `DROP TABLE`.  
> 2. Đảm bảo tính tương thích ngược (Backward Compatibility) 100% với schema gốc (`db/init/01-schema.sql`).  
> 3. Mọi thay đổi thực hiện qua tệp migration an toàn sử dụng `IF NOT EXISTS` và `ADD COLUMN IF NOT EXISTS`.  
> 4. Toàn bộ các trường tiền tệ đều sử dụng `NUMERIC(14,2)` với ràng buộc `CHECK (>= 0)`.

---

## 1. HIỆN TRẠNG SCHEMA GỐC (BASELINE SCHEMA v1.0)

Cơ sở dữ liệu ban đầu bao gồm 5 bảng nghiệp vụ, 1 bảng session và 1 sequence:
1. `public.users`: `id`, `username`, `password_hash`, `role` (admin/staff), `is_active`, `created_at`.
2. `public.customers`: `id`, `name`, `email`, `phone`, `address`, `tax_code`, `created_at`.
3. `public.invoices`: `id`, `invoice_no`, `customer_id`, `status` (DRAFT/ISSUED/PARTIALLY_PAID/PAID/CANCELLED), `currency`, `issue_date`, `due_date`, `tax_rate`, `subtotal`, `tax_amount`, `total`, `paid_total`, `cancel_reason`, `created_by`, `created_at`.
4. `public.invoice_items`: `id`, `invoice_id`, `description`, `quantity`, `unit_price`, `line_total`.
5. `public.payments`: `id`, `invoice_id`, `amount`, `method` (CASH/BANK_TRANSFER/CARD), `paid_at`, `reference`, `recorded_by`, `created_at`.
6. `public.user_sessions`: `sid`, `sess`, `expire`.
7. `public.invoice_no_seq`: Sequence sinh số thứ tự hóa đơn phát hành.

## 2. KẾ HOẠCH NÂNG CẤP VÀ MỞ RỘNG (EVOLUTION SPECIFICATION)

### 2.1. Nhánh Bảng Cũ Cần Mở Rộng (Alterations)

#### A. Mở rộng `public.customers`
```sql
ALTER TABLE public.customers
    ADD COLUMN IF NOT EXISTS code varchar(32),
    ADD COLUMN IF NOT EXISTS contact_person varchar(200),
    ADD COLUMN IF NOT EXISTS segment varchar(32) DEFAULT 'SME' CHECK (segment IN ('Enterprise', 'SME', 'FDI')),
    ADD COLUMN IF NOT EXISTS credit_limit numeric(14, 2) DEFAULT 0 CHECK (credit_limit >= 0),
    ADD COLUMN IF NOT EXISTS payment_term_id bigint,
    ADD COLUMN IF NOT EXISTS status varchar(24) DEFAULT 'ACTIVE' CHECK (status IN ('ACTIVE', 'WARNING', 'LOCKED'));

CREATE INDEX IF NOT EXISTS customers_segment_idx ON public.customers(segment);
CREATE INDEX IF NOT EXISTS customers_code_idx ON public.customers(code);
```

#### B. Mở rộng `public.invoices`
```sql
ALTER TABLE public.invoices
    ADD COLUMN IF NOT EXISTS e_invoice_code varchar(64),
    ADD COLUMN IF NOT EXISTS payment_term_id bigint,
    ADD COLUMN IF NOT EXISTS notes text;
```

#### C. Mở rộng `public.invoice_items`
```sql
ALTER TABLE public.invoice_items
    ADD COLUMN IF NOT EXISTS sku varchar(64),
    ADD COLUMN IF NOT EXISTS unit varchar(32) DEFAULT 'Đơn vị',
    ADD COLUMN IF NOT EXISTS discount_percent numeric(5, 2) DEFAULT 0 CHECK (discount_percent BETWEEN 0 AND 100),
    ADD COLUMN IF NOT EXISTS vat_rate numeric(5, 4) DEFAULT 0.10 CHECK (vat_rate BETWEEN 0 AND 0.20);
```

#### D. Mở rộng `public.payments`
```sql
ALTER TABLE public.payments
    ADD COLUMN IF NOT EXISTS bank_name varchar(100),
    ADD COLUMN IF NOT EXISTS bank_account varchar(50),
    ADD COLUMN IF NOT EXISTS notes text;
```

### 2.2. Nhánh Bảng Mới Cần Bổ Sung (New Tables)

#### A. Bảng Điều khoản Thanh toán (`public.payment_terms`)
```sql
CREATE TABLE IF NOT EXISTS public.payment_terms (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    code varchar(32) NOT NULL UNIQUE,
    name varchar(100) NOT NULL,
    days integer NOT NULL CHECK (days >= 0),
    grace_period_days integer NOT NULL DEFAULT 0 CHECK (grace_period_days >= 0),
    late_penalty_rate numeric(5, 2) NOT NULL DEFAULT 0 CHECK (late_penalty_rate >= 0),
    early_discount_percent numeric(5, 2) NOT NULL DEFAULT 0 CHECK (early_discount_percent >= 0),
    early_discount_days integer NOT NULL DEFAULT 0 CHECK (early_discount_days >= 0),
    description text,
    is_default boolean NOT NULL DEFAULT false,
    created_at timestamptz NOT NULL DEFAULT now()
);

-- Ràng buộc khóa ngoại từ customers & invoices
ALTER TABLE public.customers
    ADD CONSTRAINT fk_customers_payment_term
    FOREIGN KEY (payment_term_id) REFERENCES public.payment_terms(id) ON DELETE SET NULL;

ALTER TABLE public.invoices
    ADD CONSTRAINT fk_invoices_payment_term
    FOREIGN KEY (payment_term_id) REFERENCES public.payment_terms(id) ON DELETE SET NULL;
```

#### B. Bảng Danh mục Sản phẩm & Dịch vụ (`public.products`)
```sql
CREATE TABLE IF NOT EXISTS public.products (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sku varchar(64) NOT NULL UNIQUE,
    name varchar(255) NOT NULL CHECK (length(btrim(name)) > 0),
    category varchar(64) NOT NULL,
    unit varchar(32) NOT NULL,
    unit_price numeric(14, 2) NOT NULL CHECK (unit_price >= 0),
    vat_rate numeric(5, 4) NOT NULL DEFAULT 0.10 CHECK (vat_rate BETWEEN 0 AND 0.20),
    description text,
    status varchar(24) NOT NULL DEFAULT 'ACTIVE' CHECK (status IN ('ACTIVE', 'DISCONTINUED')),
    created_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS products_sku_idx ON public.products(sku);
CREATE INDEX IF NOT EXISTS products_category_idx ON public.products(category);
```

#### D. Bảng Biên bản Điều chỉnh & Giảm trừ (`public.invoice_adjustments`)
```sql
CREATE SEQUENCE IF NOT EXISTS public.adjustment_no_seq AS bigint START WITH 1 INCREMENT BY 1 NO CYCLE;

CREATE TABLE IF NOT EXISTS public.invoice_adjustments (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    credit_note_no varchar(32) UNIQUE,
    original_invoice_id bigint NOT NULL REFERENCES public.invoices(id) ON DELETE RESTRICT,
    adjustment_type varchar(32) NOT NULL CHECK (adjustment_type IN ('DISCOUNT', 'DECREASE_AMOUNT', 'SERVICE_RETURN', 'INFO_CORRECTION')),
    amount numeric(14, 2) NOT NULL CHECK (amount >= 0),
    vat_rate numeric(5, 4) NOT NULL DEFAULT 0 CHECK (vat_rate BETWEEN 0 AND 0.20),
    vat_amount numeric(14, 2) NOT NULL DEFAULT 0 CHECK (vat_amount >= 0),
    total_amount numeric(14, 2) NOT NULL CHECK (total_amount >= 0),
    reason text NOT NULL CHECK (length(btrim(reason)) > 0),
    status varchar(24) NOT NULL DEFAULT 'DRAFT' CHECK (status IN ('DRAFT', 'APPROVED', 'PROCESSED')),
    notes text,
    created_by bigint NOT NULL REFERENCES public.users(id) ON DELETE RESTRICT,
    approved_by bigint REFERENCES public.users(id) ON DELETE RESTRICT,
    created_at timestamptz NOT NULL DEFAULT now(),
    approved_at timestamptz

CREATE INDEX IF NOT EXISTS invoice_adjustments_invoice_idx ON public.invoice_adjustments(original_invoice_id);
CREATE INDEX IF NOT EXISTS invoice_adjustments_status_idx ON public.invoice_adjustments(status);
```

## 3. THIẾT KẾ MIGRATION AN TOÀN (IDEMPOTENT MIGRATION STRATEGY)

Tệp migration được lưu trữ tại:
`db/init/04-evolution.sql`

Và có thể được thực thi an toàn bất cứ lúc nào:
1. Mỗi câu lệnh đều có mệnh đề `IF NOT EXISTS` hoặc bọc trong khối transaction kiểm tra tồn tại.
2. Dữ liệu seed mặc định ban đầu được chèn qua `ON CONFLICT (code) DO NOTHING` hoặc `ON CONFLICT (id) DO NOTHING`.
3. Hoàn toàn không can thiệp hay xóa bất kỳ bản ghi nào đang có trong `users`, `customers`, `invoices`, `payments`.
